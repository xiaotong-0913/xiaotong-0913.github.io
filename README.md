# Xiaotong He — Personal Website

A responsive English portfolio for research and job applications. Plain HTML and CSS; no dependencies, tracking, paid services or build step.

Target address: https://xiaotong-0913.github.io/

## Publish for free

1. Sign in to GitHub as `xiaotong-0913`.
2. Create a **public** repository named `xiaotong-0913.github.io`. If it already exists, review and back it up before replacing its files.
3. Upload `index.html`, `style.css`, `.nojekyll`, `robots.txt`, `sitemap.xml` and the `assets` folder, preserving the folder structure. Alternatively, push this local Git repository to that repository.
4. Open **Settings → Pages → Build and deployment**. Choose **Deploy from a branch**, branch **main**, folder **/ (root)**, and save.
5. Wait for deployment, visit the target address and enable **Enforce HTTPS** if available.

## Local preview

Run `python3 -m http.server 8000` in this folder and open http://localhost:8000.

## Update

Edit `index.html` to change content and `style.css` for appearance. Replace `assets/Xiaotong-He-CV.pdf` to update the downloadable CV. Commit and push updates to republish.

The supplied original CV is included and contains a phone number. The web page itself displays only the public professional email, GitHub and LinkedIn. Review the PDF before making the repository public if the phone number should not be shared.

All research descriptions and citations are based on the supplied CV. No publication URLs or project repository URLs have been invented.
